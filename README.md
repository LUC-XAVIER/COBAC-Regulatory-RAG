# COBAC Regulatory RAG

A Retrieval-Augmented Generation (RAG) service that answers questions about COBAC, CEMAC and BEAC financial regulations. It answers **only** from the indexed regulatory documents and cites the source document and page for every claim.

> **Status: work in progress.** The core pipeline (loading, chunking, embedding, indexing, retrieval, generation) is implemented. The HTTP endpoints, configuration and tests are still being built. See [Project status](#project-status).

## How it works

```
PDF ──► loader ──► chunking ──► embedding ──► FAISS index + chunk store
                                                      │
Question ──► embedding ──► retriever (top-k) ◄────────┘
                               │
                         prompt builder ──► generator (Kimi K2.5) ──► answer + citations
```

1. **Load**: text is extracted page by page from each PDF (`pdfplumber`). Blank pages are skipped.
2. **Chunk**: each page is split on `Article N` headings so that one regulatory article becomes one chunk. Every chunk keeps its source file name and page number.
3. **Embed**: chunks are encoded with `intfloat/multilingual-e5-small` (multilingual, suited to French and English). Vectors are normalized.
4. **Index**: vectors go into a FAISS `IndexFlatIP` wrapped in an `IndexIDMap`. With normalized vectors, inner product equals cosine similarity. The `IndexIDMap` lets us attach our own chunk ids.
5. **Retrieve**: the question is embedded and the top-k most similar chunks are returned with scores.
6. **Generate**: the chunks are placed in a prompt that instructs the model to answer only from the provided context, to say so explicitly when the context lacks the answer, and to cite document and page.
7. **Respond**: the API returns the answer plus a list of citations (source, page, 200-character snippet).

## Requirements

- Python 3.12 or newer
- [uv](https://docs.astral.sh/uv/) (Python package and project manager)
- A free NVIDIA API key from [build.nvidia.com](https://build.nvidia.com/) (for the generator)

## Getting started

```bash
# 1. Install dependencies exactly as pinned in uv.lock
#    (uv sync creates the .venv virtual environment and installs into it)
uv sync

# 2. Provide your API key. The generator reads this environment variable.
#    Never commit the key to git.
export NVIDIA_API_KEY="nvapi-..."

# 3. Start the API with auto-reload on code changes
#    (uvicorn is the ASGI server; "app.main:app" means the `app` object in app/main.py)
uv run uvicorn app.main:app --reload
```

Interactive API documentation is generated by FastAPI at `http://127.0.0.1:8000/docs`.

On Windows, set the key in PowerShell with `$env:NVIDIA_API_KEY = "nvapi-..."`.

> The first run downloads the embedding model from Hugging Face, so it needs internet access once.

## Usage

Put the regulatory PDFs in `data/raw/`, then ingest them so they are chunked, embedded and indexed.

The two endpoints below are **planned**; their request and response shapes are defined in `app/schemas/`.

**Ingest documents** (`POST /api/v1/ingest`) returns:

| Field | Meaning |
|---|---|
| `ingested` | Files processed successfully |
| `failed` | Files that could not be processed |
| `total_chunks` | Number of chunks added to the index |
| `status` | `success`, `partial` or `failure` |

**Ask a question** (`POST /api/v1/ask`)

Request:

```json
{ "question": "What are the capital requirements for a microfinance institution?" }
```

Response:

```json
{
  "response": "…answer grounded in the retrieved articles…",
  "citations": [
    { "source": "regulation.pdf", "page": 12, "snippet": "Article 7 …" }
  ]
}
```

If nothing relevant is retrieved, the service returns a fixed message saying no relevant information was found in the indexed documents, with an empty citation list.

## Configuration

| Setting | Current value | Where |
|---|---|---|
| Embedding model | `intfloat/multilingual-e5-small` | `services/embedding.py` |
| Generator model | `moonshotai/kimi-k2.5` (override with `NVIDIA_MODEL`) | `services/generator.py` |
| API base URL | `https://integrate.api.nvidia.com/v1` (override with `NVIDIA_BASE_URL`) | `services/generator.py` |
| Max answer tokens | 1024 | `services/generator.py` |
| Chunks retrieved (`k`) | 5 | `services/rag_service.py` |
| API key | `NVIDIA_API_KEY` environment variable | environment |
